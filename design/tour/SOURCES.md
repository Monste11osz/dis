# Источники и лицензии

## Модель и изображения

Мебель, ванна, текстиль, декоративные детали и освещение собраны программно в Blender 4.3.2. Основа — ранее подготовленная модель варианта A по схеме квартиры. Рендеры и HTML используют одну сцену `Apartment_detail.blend`; свободная модель экспортирована из неё в GLB с упрощёнными материалами.

Панорамы: Blender Cycles CPU, 12–16 выборок на пиксель; заглавный рендер — 24. Шум подавлен Intel Open Image Denoise 1.4.3 с цветом, нормалями и albedo. Преобразование цвета — AgX. Это расчётные изображения сцены, без генеративной дорисовки геометрии. Разрешения и параметры каждого изображения находятся в исходном архиве, `tour/renders/*.json`.

## Внешние ресурсы

- **Fabric036**, Lennart Demes / [ambientCG](https://ambientcg.com/view?id=Fabric036), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/): карта нормалей ткани, 512 × 512. Получена из [зеркала Papyszoo](https://github.com/Papyszoo/CC0-Public-Domain-Textures) версии `84af0b4614c22c9028143da786fe6f9889bfee70`; декодирована из KTX2 в PNG. Масштаб и сила рельефа настроены для модели.
- **Venice Sunset**, [Poly Haven](https://polyhaven.com/a/venice_sunset), [CC0](https://polyhaven.com/license): HDRI освещения 1024 × 512. Файл получен из [pmndrs/drei-assets](https://github.com/pmndrs/drei-assets/blob/master/hdri/venice_sunset_1k.hdr), без изменения. Не является видом из окон квартиры.
- Древесина и мелкий рельеф штукатурки/ткани дополнительно заданы процедурно; это визуальные материалы, не каталог конкретного производителя.
- **Three.js 0.170.0**, MIT: движок просмотра, OrbitControls, GLTFLoader, RGBELoader. Полный текст лицензии встроен в HTML и приложен в архиве.
- **esbuild 0.24.2**, MIT: инструмент сборки исходного JavaScript, не требуется пользователю для просмотра.
- **Intel Open Image Denoise 1.4.3**, Apache-2.0; Python-обёртка `oidn==0.2.1`: инструменты подготовки рендеров, не входят в браузерное приложение. Зависимости рендеринга и Blender устанавливаются отдельно.

Исходная фотография пользователя служила референсом стиля и в распространяемые файлы не включена. Исходные видео и PDF пользователя в новый архив не добавлены.
